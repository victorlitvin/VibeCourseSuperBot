# VibeCourseSuperBot

Простой учебный Telegram-бот на TypeScript. Работает без сторонних библиотек —
напрямую через Bot API с long polling на встроенном `fetch`.

## Что умеет бот

- Принимает обновления от Telegram через `getUpdates` (long polling, ожидание 30 секунд).
- Читает текст каждого нового сообщения и печатает его в консоль.
- Пропускает уже обработанные обновления (использует `offset`) и переживает ошибки Bot API,
  продолжая опрос дальше.

Сейчас бот только слушает сообщения и выводит их текст в консоль — ответы пользователю не отправляются.

## Требования

- Node.js 20.6+ (проверено на Node.js 24)
- npm

## Установка

```bash
npm install
```

## Настройка

1. Получите токен бота у [@BotFather](https://t.me/BotFather) в Telegram (команда `/newbot`).
2. Скопируйте шаблон переменных окружения в `.env`:

   ```bash
   copy .env.example .env      # Windows
   cp .env.example .env        # macOS / Linux
   ```

3. Вставьте токен в `.env` после знака `=` (без кавычек):

   ```
   BOT_TOKEN=123456789:AAH...xyz
   ```

Файл `.env` содержит секрет и не коммитится в git (он в `.gitignore`).

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Запуск в режиме разработки с автоперезапуском (`tsx watch`) |
| `npm run typecheck` | Проверка типов без сборки (`tsc --noEmit`) |
| `npm run build` | Сборка TypeScript в папку `dist/` |
| `npm start` | Запуск собранной версии (`dist/index.js`) |

## Запуск

Для разработки:

```bash
npm run dev
```

Отправьте боту сообщение в Telegram — его текст появится в консоли.

Для запуска собранной версии:

```bash
npm run build
npm start
```

## Структура проекта

- `src/index.ts` — код бота: long polling и вывод полученных сообщений
- `src/config.ts` — чтение переменных окружения
- `.env.example` — шаблон переменных окружения (коммитится)
- `.env` — реальные значения, в т.ч. `BOT_TOKEN` (не коммитится)
- `dist/` — результат сборки (`npm run build`)
